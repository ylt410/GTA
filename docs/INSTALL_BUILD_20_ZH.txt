GTA V Port 1.4.6（构建 20）— 综合性能修正版

下载 GTA5Port_1.4.6_b20.ipa；安装后核对 v1.4.6 (20)。

本轮一起修改的路径：
1. GPU 完成等待按实际完成状态唤醒，不再积累旧信号；乱序回调全部
   完成后才允许回收之前的缓冲，避免提前复用仍被回调使用的数据。
2. 上传缓冲回收只检查实际持有常量快照的对象，取消整张对象表扫描。
3. 分块读取的模组资源复用文件句柄；一次读完的冷文件不挤掉常用归档
   的句柄。缓存仍为 64 项，没有靠扩大缓存上限换取测试结果。
4. 本地资源预读改为系统的有界预读提示，不再读入临时缓冲再丢弃。
   预读失败不会改变真正读取游戏资源的结果。
5. 自动记录整帧卡顿、CPU 时间、分组 GPU 时间、等待和内存，供实测排查。

多线程保留：
画质底部“引擎并行度”仍可选 2、4、6，修改后完全退出再打开应用。
自动暂用原来的 2 核配置。构建 19 卡顿加重的原因尚未单独隔离，
不能断言是线程导致；4/6 没有删除。若要单独比较本轮其他修复，
请把两版都设成同一个核心数，例如都用 4，保持画质、帧率上限和场景一致。
CPU 总占用高不等于线程越多越快，是否有用应看每帧耗时及卡顿分布。

记录默认自动生效，无须打开调试开关：
进入游戏世界后，每 15 秒在 native-port.log 写一条 [performance]。
native-performance.json 只保存最近一个窗口，不会一直追加长大。
P50/P95/P99 是源帧间隔的 1 毫秒上界；同时记录超过 50/100/250 毫秒的帧。
CPU 时间是进程所有线程合计的毫秒/源帧，另列渲染线程自身 CPU 时间。
GPU 时间按一整源帧的全部命令缓冲汇总，等待所有回调完成，缺失或错误
的时间戳会标为无效。GPU 完成窗口与 CPU 窗口可能相差在途帧，分别列出
帧数，不能冒充完全配对的 GPU 利用率百分比，也不能直接比较旧版错误口径。
Metal 分配内存已包含在进程占用中，不应把两者相加。
这些记录只在本地，默认不会上传任何服务器。

验证范围：并发唤醒/乱序回调、快照生命周期、真实模组归档读取、
一次性文件缓存策略、预读范围和失败处理、Swift/iOS SDK 及 IPA 校验。
没有连接你的 iPhone 运行游戏，因此暂没有整游戏帧率和开销的改善百分比。
AI 插帧仍已删除；保留 LSE 原子指令和 A17 编译调度。本私人版本要求 A11
或更新设备；旧 iPad 继续使用构建 18。

覆盖安装前备份游戏、模组和存档，保留相同签名身份与应用标识。
不需要删除应用来显示本轮选项。旧私人发行仍保留。
