GTA V Port 1.4.6（构建 21）— 乡村驾驶与资源内存修复

下载 GTA5Port_1.4.6_b21.ipa，安装后核对 v1.4.6 (21)。
覆盖安装前备份游戏文件、模组及存档；保持原来的应用标识和签名身份。

这次直接改 APP 的加载和回收逻辑：
1. 分开计算玩家设定的物理内存上限与引擎虚拟地址空间。
   例如系统允许 6144 MB、玩家设定 5120 MB 时，物理预算仍是 5120 MB，
   引擎虚拟预留从约 4096 MB 改为 5120 MB。虚拟预留不等于立即占用
   同样数量的物理内存。系统不允许较大映射时仍会按原流程回退。
2. 曾经用于模型的共享缓冲，整块空闲且 GPU 已完成读取后可以释放。
   保持索引稳定，延迟释放的范围不能被提前复用。普通情况下保留少量
   热备块；内存守卫、实际堆增长或系统内存警告会请求提前回收空块。
3. 纹理或模型块创建失败时，只有确认释放了完成使用的空块才重试一次。
   正在使用的地图、纹理和模型不会作为缓存被直接丢掉。

继续保留当前画质、物理内存上限和引擎并行度；本轮不自动降低画质。
先用以前会出问题的乡村驾驶路线验证，并记录持续驾驶多久后出现变化。

Engine virtual mapping：经过权限检查和回退后实际映射的虚拟容量。
mesh slab memory：活动/等待 GPU 的字节、保留空块与累计释放量。
已有 native-performance.json 和 native-port.log 继续在本地记录。

验证范围包括物理/虚拟预算分离、边界与回退策略、GPU 完成序号保护、
空块回收、稀疏索引复用、失败重试准备、30,000 次模型分配/释放事件，
以及完整 iOS 编译和 IPA 校验。手机上的实际恢复情况需要同路线验证；

损坏；重压 RPF 只改变磁盘体积，也不会直接减少解压后的运行内存。
