随包的 Performance-Benchmarks.json 是测试报告：
CPU 是指定子系统的配对测试；内存包括突发加载后的暂存资源回收测试；
GPU 如可使用运行器的 Metal 设备，会记录真实 GPU 时间戳和相同图像校验。
运行器没有 GPU 或时间戳时明确记为跳过或 null。
这些结果不等于你的 iPhone 整游戏 CPU/GPU/内存降幅，也不是 FPS 承诺。
