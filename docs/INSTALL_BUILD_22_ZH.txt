GTA V Port 1.4.6（构建 22）— CPU / GPU 效率修正版

下载 GTA5Port_1.4.6_b22.ipa，安装后核对 v1.4.6 (22)。保持原来的签名身份，
覆盖安装前备份游戏、模组与存档。当前画质、物理内存预算、核心数选择保留。

本轮直接修改客户端，默认生效：
1. 图形、资源、任务线程的等待队列按地址分开加锁，并隔开锁所在的缓存行，
   减少互不相关的线程在同一把锁上排队。没有靠额外增加线程实现此项修改。
2. 深度代理只复制当前着色器视图实际能读取的 mip 和数组层。已有内容按
   子资源记有效状态，原图写入、生成 mip 或对象替换后重新失效。
   画面所需数据保持一致，原来的分辨率、阴影、模型和贴图质量不降低。
3. 保留构建 21 的虚拟地址/物理预算分离、完成后空闲模型缓冲回收。
   原来的 2/4/6 核选择继续可用。本轮没有修改原有核心数默认策略。

随包的 A17-Efficiency-Validation.json 是构建机的子系统结果：
futex 是固定次数请求/应答的 CPU 时间和吞吐；Metal 项是独立深度复制
测试，并非 GTA5 全游戏。构建机没有 GPU 时会明确记为 SKIPPED。
这些数字不能作为 iPhone 15 Pro 的整游戏 CPU/GPU 占用或 FPS 改善百分比。

在手机上比较：
1. 尽量在更新前保存旧版本同一场景、稳定运行后的 native-performance.json。
2. 新版使用相同画质、帧率上限、引擎核心数、车辆与路线，待加载稳定后再记录。
3. 比较 sourceFps、cpuMsPerSourceFrame、gpuMsPerCompletedFrame 与 P95/P99。
   GPU 完成窗口可能滞后于 CPU，帧数分别记录；不把它当作硬件利用率。
4. FPS 上升时总 CPU/GPU 占用可能上升，评估效率应同时看每帧耗时与画面工作量。
日志中的 depth proxies since launch 显示实际复制量与原来全量复制的参考量。

配套游戏文件已定位到 ylt410/playgta5（来源 alihammoud21/playgta5）。
引擎哈希与客户端一致；按字节范围下载了约 126 MiB 的乡村和树木归档样本，
校验后抽查 41 个纹理字典，1027 张纹理大多已有 BC 压缩和多级 mipmap，
边长不超过 1024。本轮没有盲目缩小这些贴图或重新打包整套游戏。
